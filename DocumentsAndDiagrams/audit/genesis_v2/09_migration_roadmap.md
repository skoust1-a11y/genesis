# 09 — Migration roadmap

Order is the Sprint 2 register, with two gates in front so the crew diagram is not implemented by accident. No task enables live trading, places an order, edits `active_strategy_params.json`, rewrites historical JSON, or changes a PDC predicate.

Backward compatibility: old journal rows stay byte-for-byte. The reserve number 213954.1 is copied, not recomputed. `ExecutionManager` stays unwired. The LangGraph deployment crew stays on the live database.

## Not in this roadmap

Broker adapters, margin from a broker, edits to holding, exit, or sweep thresholds, wiring `trading/orders.py` into the daemon, enabling `LIVE_TRADING_ENABLED`, recomputing 213954.1, and a new orchestration framework.
